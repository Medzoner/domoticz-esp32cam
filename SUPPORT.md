# Support

Use the project channels according to the type of request:

- **Questions and setup help:** [GitHub Discussions](https://github.com/Medzoner/domoticz-esp32cam/discussions)
- **Reproducible bugs:** use the bug report issue form
- **Feature and board proposals:** use the corresponding issue form
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md)

Include the board, camera sensor, firmware release or commit, client software,
and sanitized serial output. Never post credentials, cookies, private camera
images, or sensitive network details.

Support is provided by the community on a best-effort basis. There is no SLA or
guarantee of compatibility with unsupported hardware.
